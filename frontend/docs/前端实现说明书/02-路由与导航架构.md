# 02 · 路由与导航架构

## 1. 路由实例

`src/router/index.js:83-87`

```js
const router = createRouter({
    history: createWebHistory(),   // HTML5 History 模式，无 base 前缀
    routes: [ /* 见下表 */ ],
})
```

- 使用 **History 模式**（非 hash）。部署时需服务端配置 SPA fallback（所有路径回退到 `index.html`）。
- **没有** `scrollBehavior` 配置。
- **没有**全局前置守卫（`beforeEach`）—— 权限控制由菜单显隐 + 组件内判断完成（见第 4 节）。

## 3. 布局与导航（`visualization.vue`）

### 3.1 布局结构

`src/components/visualization.vue` 是全工程**唯一的主框架**，使用 Element Plus 容器：

```
<el-container>
  ├── <el-header>   顶栏：Logo「InnovationCore AI Platform」+ 一级导航 + 用户名
  ├── <el-container>
  │     ├── <el-aside>   侧边菜单（按 currentModule 渲染不同菜单树）
  │     └── <el-main>    <router-view/>
  └── 登录弹窗（<Login v-if="!token"/>）
```


> `localStorage.getItem('username')`（见 05 文档登录章节）。

## 5. 路由与组件的映射要点

1. **同一组件挂多路径**：
   - `textConversation.vue` ← `/chat` 与 `/experienceCenter/textConversation`
   - `userStatistics.vue` ← `/userStatistics`、`/userStatistics/eval`、`/userStatistics/apikey`
   - `evalMapView.vue` ← 全部 6 条 `/evalMap/*`
   - 组件内部通过 `useRoute().path` 区分展示内容。

2. **`deviceDetail/:id`** 是全工程唯一带**动态参数**的路由。

3. **路由懒加载**：**完全没有使用** `() => import(...)`，所有组件在 `router/index.js`
   顶部**静态 import**，导致首屏 bundle 巨大（因此有 3.3 的 manualChunks 配置兜底）。

4. **无 `Not Found` 路由**：未定义 `/:pathMatch(.*)*` 兜底，访问未知路径时
   `<router-view>` 渲染空白。
