### 5.1 `modelDeploy.vue` 轮询机制（重点）

```js
const FAST_INTERVAL = 2000     // 有模型部署中 → 2 秒
const SLOW_INTERVAL = 600000   // 全空闲 → 10 分钟

let containerTimer = null      // 容器/空闲卡列表定时器
let progressTimer = null       // 部署进度定时器（有部署任务时独立运行）

function startContainerRefresh(interval) {
  if (containerTimer) clearInterval(containerTimer)
  containerTimer = setInterval(() => refreshStatus(), interval)
}
function stopContainerRefresh() { clearInterval(containerTimer); containerTimer = null }

function startProgressPolling() {
  if (progressTimer) return       // 已在轮询中 → 幂等
  progressTimer = setInterval(() => checkDeployingStatus(), FAST_INTERVAL)
}
function stopProgressPolling() { clearInterval(progressTimer); progressTimer = null }
```

**状态映射**：

| 后端状态 | 中文 |
|---|---|
| `IDLE` | 空闲 |
| `PENDING` | 排队中 |
| `RUNNING` | 部署中 |
| `SUCCESS` | 已完成 |
| `FAILED` | 失败 |

**自适应策略**：监听「是否有部署中任务」，动态在 `FAST_INTERVAL`(2s) 与
`SLOW_INTERVAL`(10min) 之间切换容器刷新频率，**全空闲时大幅降频**以省资源。

**接口**：`api/deployApi.js`，基址 `http://7.216.57.45:10910/`。
