# 03 · 状态管理

工程**同时使用 Pinia 与 Vuex 4**，二者在 `src/main.js` 中同时注册：

```js
import { createPinia } from 'pinia'
import stores from './stores';
...
app.use(createPinia())
app.use(stores)        // Vuex 根 store
```

- **Pinia** 用于新代码（模型列表、对话会话、数据集、UI 开关）。
- **Vuex** 用于历史代码（榜单筛选条件、分页、翻译模块）。
- `src/stores/index.js` 既是 Vuex 根 store，也是 Pinia store 的**同级目录**（命名易混）。

### 5. `useRankingStore` — `ranking`

文件：`src/stores/rankingStore.js`（300+ 行，含核心业务解析逻辑）

**导出常量**

| 名称 | 说明 |
|---|---|
| `DATASET_MAPPING` | 数据集映射表（`ruler1`、`service`、`box_tool_use`、`aisf_llm_gaixie` 等） |
| `extractedParam(modelName)` | 从模型名提取参数规模（如 `7b` → `7B`），无匹配返回 `STRINGS.DASH` |

`DATASET_MAPPING.ruler1` 结构：

```js
{
  subsets: ['mmlu','mmlu_redux','aime24','aime25','aime26',
            'live_code_bench','gpqa','bfcl_v3','ifeval'],
  labels: { mmlu:'MMLU', mmlu_redux:'MMLU-Redux', aime24:'AIME2024',
            aime25:'AIME2025', aime26:'AIME2026',
            live_code_bench:'LiveCodeBench', gpqa:'GPQA-Diamond',
            bfcl_v3:'BFCL', ifeval:'IFEval' }
}
```

`DATASET_MAPPING.service`：

```js
{ subsets: ['tool_chose','param_extra','intent_detect'],
  labels: { tool_chose:'工具选择', param_extra:'工具填参', intent_detect:'意图识别' } }
```

`DATASET_MAPPING.box_tool_use` 与 `aisf_llm_gaixie` 的 subsets 为中文场景名
（如「上下文信息无法支持内容补全」「需指代消解」「意图模糊」「意图完备」等）。

**state**

| 字段 | 说明 |
|---|---|
| `ruler1Values` | 尺子一解析结果数组 |
| `ruler2Values` | `{ aisf_llm_gaixie: [], aisf_llm_yitu: [] }` |

**actions**

| 名称 | 说明 |
|---|---|
| `getRankingData()` | 调 `getCurrentFullRes()`，交给 `processRawData` |
| `processRawData(rawData)` | 分发到 ruler1 / ruler2 处理 |
| `processRuler1ModelData(data)` | 遍历 `[modelName, modelGroup]`，收集 subsets 分数与 `average` |
| `processRuler2ModelData(data)` | 遍历 `metric.categories[].subsets[]` 展平取分，计算均值 |

**ruler1 输出对象结构**：

```js
{ id, name, createTime, updateTime, type,
  averageScore: Number, publisher, new: bool,
  parameter, subsets: [{ key, score }] }
```

**ruler2 输出对象结构**：

```js
{ id, name, createTime, updateTime, type,
  averageScore, publisher, new, parameter,
  subsets: [{ key, score, tri_subsets }] }
```

**ruler2 均值算法**（`rankingStore.js:277-280`）：过滤 `score !== -1` 后取算术平均，
`toFixed(4)`，空数组时为 `'0.0000'`。

### 4.2 持久化策略对比

| 方式 | 实现 | 示例 |
|---|---|---|
| **显式同步写** | 在 action 中手动 `localStorage.setItem` | `AISchool.js`、`commonChatActions` |
| **watch 深度监听** | `watch(..., {deep:true})` 后写 | `PipelineView.vue:92-96` |
| **无需持久化** | 纯内存 | 大多数 store |

### 4.3 会话恢复机制

- **PipelineView**：`onMounted(restorePipeline)`，读取 `automatic-pipeline-circuit-v3`；
  `version !== 3` 时**丢弃并删除**；`status === 'running'` 恢复为 `'paused'`（避免"幽灵运行"）；
  `onBeforeUnmount(clearTimer)` 清理定时器。
- **DataPublishingView**：`ACTIVE_UPLOAD_KEY` 记住进行中的上传 job。
- **CollectionView**：`ACTIVE_JOB_KEY` 记住进行中的构建 job。
- **TaskAugmentationView**：`persistedJobKey` 记住 job（用 try/catch 包裹以容忍 storage 不可用）。
