### 加载机制

`src/dataPipeline/overview/icons.js`：

```js
const modules = import.meta.glob('../assets/overview-icons/*.jpg',
                                 { eager: true, import: 'default' })
```

- 使用 **`import.meta.glob`**，Vite 在**构建时**收集全部匹配文件的 URL 并内联到 bundle。
- **因此：新增图标文件后必须重新构建**，运行时新增不会生效。
- 键名格式：`../assets/overview-icons/{appName}.jpg`

### ✅ 缺失影响（低风险）

`getAppIconTexture` 有**字母兜底**：

```js
if (url) { tex = new THREE.TextureLoader().load(url); tex.colorSpace = THREE.SRGBColorSpace }
else     { tex = makeLetterIconTexture(appName) }   // 渲染首字母
```

**→ 即使 19 个图标全部缺失，3D 总览仍可正常运行**，
只是 App 显示为「字母圆形图标」而非真实 App Logo。

> 但若删除 `icons.js` 中的 `import.meta.glob` 行，则会因 glob 空匹配而行为变化，**不要改代码**。

| 类型 | 可否重建 | 说明 |

| Word 模板（`EvaluationReport.docx`） | ⚠️ 部分 | 若有模板结构说明可重制，但版式难 100% 还原 |
| App 图标（`overview-icons/*.jpg`） | ⚠️ 可用字母兜底 | 有代码级降级路径 |
