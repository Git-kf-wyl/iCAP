### 4.1 关键设计约定

1. **`api/` 与 `services/` 分离**
   - `api/*.js`：无状态，`export const fn = (payload) => axios.post(...)`，返回 `AxiosResponse`。
   - `services/*.js`：`class + static` 方法，含缓存/映射逻辑（如模型图标、颜色），返回 `res.data`。

2. **状态双轨制**
   - **Pinia**：新代码（模型、会话、数据集、dataPipeline 的 UI 状态）。
   - **Vuex**：历史代码（榜单筛选条件、任务表、结果表、翻译模块）。
   - 两者在 `main.js` 同时注册，互不干扰。

3. **dataPipeline 的隔离**
   - 所有样式挂在 `.dp-root` 下，避免污染主工程（`dataPipeline.global.css:14`）。
   - 使用独立 `fetch` 客户端与独立的 `VITE_API_BASE_URL` 前缀。
   - 布局组件 `DataPipelineLayout.vue` 仅一个 `<router-view/>`。

4. **`llm_bench` 的隔离**
   - 完全独立于 Vue，通过 `src/components/dataCenter/evalMapView.vue` 的 `<iframe>` 加载，
     并用 hash 路由映射（`/evalMap/benchmarks` → `#/benchmarks`）。

## 5. 运行入口链路

```
index.html
  └─ <script type="module" src="/src/main.js">
       ├─ createApp(App)
       ├─ app.use(ElementPlus, {locale: zhCn})      # 中文语言包
       ├─ 注册全部 @element-plus/icons-vue 为全局组件
       ├─ app.use(router)                            # src/router/index.js
       ├─ app.use(createPinia())                     # Pinia 实例
       ├─ app.use(stores)                            # src/stores/index.js (Vuex)
       └─ app.mount('#app')
```

`App.vue` 只做两件事：
1. 渲染 `visualization.vue`；
2. `onMounted` 调 `useAIModelStore().fetchModels()` 预热模型列表。

## 6. 环境变量

工程**没有** `.env` 文件（`ls -a` 无结果，`.gitignore` 也不存在）。
唯一消费的环境变量：

| 变量 | 消费点 | 说明 |
|---|---|---|
| `VITE_API_BASE_URL` | `src/dataPipeline/api.ts:3` | dataPipeline 模块请求前缀，未设置则为空串（走同源 + vite 代理） |

其余所有后端地址均为**源码硬编码**（`src/utils/Constants.js`）。
