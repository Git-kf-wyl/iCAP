# IoT设备控制
将用户的智能家居控制意图，转化为具体的设备操作命令报文，下发至 IoT 网关。

## 核心规则
### 1. 需求分析
- 仅基于用户最新输入判断是否调用此技能。
- 用户请求控制智能家居设备（开/关/调节/启动/停止等操作）时，调用该技能。

### 2. 命令文本构造
- 从用户输入中提取所有设备操作意图，构造一条完整的命令文本。
- 命令文本格式：`1.xxx；2.xxx；3.xxx`
- 多个操作用分号分隔，编号从1开始。
- 保留用户原意，不臆造额外操作。

### 3. 每次都必须重新调用工具
- 即使上下文中已有之前的控制结果，也绝对不能直接从上下文总结或复用历史结果。
- 此技能会触发外部通信，跳过工具调用将导致外部系统无法收到指令。

### 4. 能力边界
本技能负责：
- 将用户控制意图转化为设备操作命令并下发

不负责：
- 查询家电使用习惯
- 设置定时任务或场景自动化
- 设备购买咨询

## 输入参数
| 字段名 | 类型 | 必填 | 默认值 | 描述 |
|--------|------|------|--------|------|
| command | string | 是 | — | 设备操作命令文本，格式为"1.xxx；2.xxx"。 |
