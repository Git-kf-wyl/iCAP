## 适用场景

当用户表达以下意图时激活本 skill：

* 设置吃药提醒、服药提醒、用药提醒
* 用户或上游结果中提供药品、用药数量、用法用量、提醒时间等信息，并要求提醒

## 参数提取规则

| 字段名            | 类型    | 必填 | 描述                                 |
| -------------- |-------| -- | ---------------------------------- |
| medicationList | array | 否  | 药品信息列表。单个或多个药品均使用该字段；无可确定药品信息时不输出。 |

### medicationList 列表项字段

`medicationList` 中每个对象表示一个药品提醒任务。

| 子字段名           | 类型     | 必填 | 描述                                   |
| -------------- | ------ | -- |--------------------------------------|
| medicationName | string | 否  | 药品名称。仅在明确出现药品名称时输出。                  |
| quantity       | string | 否  | 用药数量。如“一袋”， 仅在用户输入、上下文或上游结果中明确提供时输出。 |
| cron           | string | 否  | 5 段 cron 表达式。仅在命中明确时间或固定频次映射时输出。     |

每个对象只输出可确定的子字段，不要为了补齐结构输出空字符串、null、空数组或空对象。

## 通用提取规则
* 只提取用户当前输入、上下文唯一明确内容或上游结果中明确存在的信息。
* 当前用户输入与上下文或上游结果冲突时，以当前用户输入为准。
* 未明确提供的字段不传。
* 不得根据药品名称、药品类型、用药习惯或默认经验推断 `quantity` 或 `cron`。

## medicationList 提取规则

* 单个药品和多个药品均使用 `medicationList`。
* 每个药品生成一个对象。
* 每个对象只允许输出 `medicationName`、`quantity`、`cron`。
* 每个药品的 `quantity` 和 `cron` 独立判断，不得把一个药品的信息套用到另一个药品。
* `quantity` 表示用药数量，只从用户输入、上下文或上游结果中明确存在的数量字段或数量文本中提取，禁止自行改写、换算或推断。
* 如果没有任何可确定的药品信息，不输出 `medicationList`。

## cron 规则

`cron` 只能在该药品对应文本中存在明确 cron 证据时生成。没有 cron 证据时，禁止输出 `cron`。

cron 证据只包括以下两类：

1. 固定频次表达：

   * 一日三次 / 每日三次 / 一天三次 / tid
   * 一日两次 / 每日两次 / 一天两次 / bid
   * 一日一次 / 每日一次 / 一天一次 / qd

2. 明确时钟时间表达：

   * 每天X点
   * X点半
   * X点Y分
   * HH:MM
   * 上午X点
   * 下午X点
   * 晚上X点
   * 多个明确时间点，如“每天8点、13点、18点”

生成 `cron` 前，必须能在该药品对应文本中找到上述原文证据。找不到原文证据时，不输出 `cron`。

以下内容不是 cron 证据，不能生成 `cron`：

* 药品名称
* 用药数量，如“1片”“2粒”“1袋”“6瓶”
* 单次用量，如“一次1片”“一次1袋”“每次2粒”
* 剂量、规格、浓度、包装、单位换算
* 给药方式、医嘱备注
* “用法用量”“usageDosage”等字段名或描述词本身
* 饭前、饭后、睡前、必要时、疼痛时、外用

特别注意：

* “一次1片 / 一次1袋 / 每次2粒”只表示 `quantity`，不得生成 `cron`。
* 只有“一日一次 / 每日一次 / 一天一次 / qd”才可以生成一次频次的 `cron`。
* 禁止根据药品类型、常见服药习惯、默认饭点、默认作息、历史习惯或示例内容补出 `cron`。
* 每个药品的 `cron` 只能来自该药品对应文本，不能把一个药品的频次或时间套用到另一个药品。

## 固定频次映射

固定频次映射是封闭枚举规则：当输入命中任一固定频次表达时，cron 必须且只能取该表达对应的映射值，禁止基于常识、习惯、语义相近、时间偏好或模型自行理解生成映射表以外的 cron。

* 一日三次 / 每日三次 / 一天三次 / tid → `0 8,13,18 * * *`
* 一日两次 / 每日两次 / 一天两次 / bid → `0 13,18 * * *`
* 一日一次 / 每日一次 / 一天一次 / qd → `0 13 * * *`

## 明确时间映射

* `X点` → `0 X * * *`
* `X点半` → `30 X * * *`
* `X点Y分` → `Y X * * *`
* `HH:MM` → `MM HH * * *`
* 上午、早上按原小时处理；下午、晚上转换为 24 小时制。
* 多个时间点只有分钟相同时才允许合并；分钟不同则不输出 `cron`。

## 上游结果规则

当参数来自上游 skill 返回结果时，只从明确存在的药品数组或药品文本中提取，如 `outpatientDetails`、`medicationInfo`。

必须用 `medicationList` 输出全部药品，不能只取第一种。每项映射规则：

* `medicationName` → `medicationName`
* `quantity` → `quantity`
* `usageDosage` → 仅作为该药品的文本来源之一，不输出 `usageDosage`

只有当 `usageDosage` 内容本身包含固定频次表达或明确时钟时间表达时，才允许按 cron 规则生成该药品的 `cron`。

如果 `usageDosage` 只包含数量、剂量、规格、浓度、包装、给药方式、单位换算或医嘱备注，不输出 `cron`。

如果当前 content 中的“用法用量”内容未命中固定频次表达或明确时钟时间表达，不输出 `cron`。
