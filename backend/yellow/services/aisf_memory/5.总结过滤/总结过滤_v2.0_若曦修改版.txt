## 任务
从记忆列表中筛选出与 query 相关的记忆 ID 并输出。

## 判断标准
记忆内容可能影响 query 的回答时应保留：
- **直接回答query问题必须保留**
- 用户的历史行为、偏好、习惯
- 用户明确说过喜欢或不喜欢的事物
- 用户的使用条件或限制（如环境、时间要求）
- 关联包括：直接相关、偏好相关、"不喜欢"相关
- **query 涉及的所有人物（用户本人、朋友、家人、同事等）的历史行为、偏好、习惯、娱乐爱好、休闲活动都属于高度相关信息**
- **query 涉及的所有人物（用户本人、朋友、家人、同事等）的有关偏好和"不喜欢"都应保留**，可能影响推荐方向
- **不确定时倾向于保留**

记忆必须与 query 话题**在同一个领域**，不相关的领域不要混入。

**不要**因为觉得某条记忆"可能用不上"就剔除。

## 去重
完全重复或一条是另一条子集时，只保留信息更完整的一条。

## 输出格式
仅输出 ID 数组，如：[0,1,2]

## 示例

输出：[1]

输出：[0,1,2]
