## 任务
你是专业记忆筛选处理器。从记忆列表中筛选出与 query 相关的记忆，输出思考过程与筛选结果。

## 判断标准
逐条判断记忆是否与 query 相关，不确定时一律保留。按以下步骤执行：

1. 提取 query 核心话题
   - 识别 query 在问什么，用户对该话题的喜好与排斥均在匹配范围内
   - 识别 query 中涉及的所有人物（用户本人、朋友、家人、同事等），这些人物的偏好、习惯、"不喜欢"都属于高度相关信息
   - query 以';'分隔时视为多个独立维度，对每个维度分别匹配

2. 逐条判断记忆是否相关
   - 记忆能直接回答 query 问题 → 保留
   - 记忆涉及 query 话题或 query 中人物的历史行为、偏好、习惯、使用条件 → 保留
   - 记忆与 query 话题明显不在同一领域 → 剔除
   - 不确定是否相关 → 保留

3. 不预判有用性
   - 只判断记忆与话题是否相关，不预判记忆对最终回答是否有用
   - 不做跨领域联想，不因"可能用不上"而剔除

4. 剔除前二次确认
   对准备剔除的每条记忆，反问自己：这条记忆在任何合理角度下是否可能与 query 有关？只要不是明显无关，改判为保留。

## 去重
完全重复或一条是另一条子集时，只保留信息更完整的一条。

## 输出格式
按保留/剔除分组列出 ID 并简述归类依据，末尾输出 ID 数组：

思考过程：保留id=0,2（与query直接相关），剔除id=1,3（无关领域）。去重后id=4包含id=5的全部信息，仅保留id=4。
[0,2,4]

无相关结果时：
思考过程：所有记忆均与 query 话题无关，无相关记忆可保留。
[]

## 示例
输入：{"query":"用户运动偏好", "memory_list":[{"id":0,"content":"用户喜欢吃甜食"},{"id":1,"content":"用户每周跑步两次"},{"id":2,"content":"用户对海鲜过敏"}]}
输出：
思考过程：保留id=1（跑步习惯，与运动直接相关），剔除id=0,2（饮食偏好、食物过敏，与运动无关领域）。
[1]

输入：{"query":"家庭聚餐该怎么安排", "memory_list":[{"id":0,"content":"用户喜欢吃火锅和烧烤"},{"id":1,"content":"用户不喜欢吃云南菜"},{"id":2,"content":"父母家在建国路"}]}
输出：
思考过程：保留id=0,1,2（饮食偏好和家庭地点，均与家庭聚餐安排直接相关）。
[0,1,2]

输入：{"query":"我周末打算去周边玩", "memory_list":[{"id":0,"content":"用户去年考取了驾照"},{"id":1,"content":"用户每天7点起床"},{"id":2,"content":"用户的手机号"}]}
输出：
思考过程：保留id=0（驾照，与自驾出行相关），剔除id=1,2（起床时间、手机号，与出行无关领域）。
[0]

思考过程：保留id=0,1,3,6,7（养宠历史、猫毛过敏和养宠偏好，均与query两个维度直接相关），剔除id=2,4,5,8,9,10,11（爬山、设备、通勤、消费、疫苗、银行、旅游等无关领域）。
[0,1,3,6,7]

输入：{"query":"我喜欢看什么类型的电影？平时习惯什么时候看？","memory_list":[{"id":0,"content":"用户每周五晚上会看一部科幻电影"},{"id":1,"content":"用户不喜欢爱情片，觉得太拖沓"},{"id":2,"content":"用户办公桌上的绿植是绿萝"},{"id":3,"content":"用户喜欢克里斯托弗·诺兰导演的作品"},{"id":4,"content":"用户家里养了一只橘猫，名叫大黄"},{"id":5,"content":"用户通常用手机投屏到电视看电影"},{"id":6,"content":"用户昨天买了一件蓝色冲锋衣"},{"id":7,"content":"用户认为《星际穿越》是最佳科幻片"},{"id":8,"content":"用户的房贷每月还8000元"},{"id":9,"content":"用户看电影时会吃原味薯片"},{"id":10,"content":"用户不喜欢惊悚片，觉得太压抑"},{"id":11,"content":"用户最近在学做红烧肉"}]}

思考过程：保留id=0,1,3,5,7,9（电影类型偏好和观影习惯相关信息），剔除id=2,4,6,8,10,11（绿植、宠物、购物、房贷、烹饪等无关领域）。
[0,1,3,5,7,9]
